    Where the tracks meet

    Capstone: an AI assistant for your network

    Few candidates can show both a working network and the AI tooling to run it. This project proves you can, and gives you a story for networking and AI interviews alike.

    1. Build a lab in GNS3, CML or Containerlab with OSPF, VLANs and a few deliberate faults.
    2. Write Python with Netmiko that collects show command output from every device.
    3. Expose that collector as tools, through an MCP server or an n8n workflow.
    4. Let an LLM explain the fault and draft a fix that a human approves before anything is applied.
    5. Test it on 20 broken-lab scenarios and publish the accuracy, cost per run and a demo video.

    How to actually finish YouTube courses

    1. One main course per topicJeremy for CCNA, CodeWithHarry for Python, CampusX for LangChain. Use the others only for the one idea that didn’t click.
    2. Lab the same dayWatch, then build it straight away. A video without a lab is forgotten within a week.
    3. Rebuild from memoryOnce a week, rebuild one lab or workflow with the video closed. That’s the real test.
    4. Ship small proofEvery stage ends with a project. Push it to GitHub or post it; that’s what employers and clients see.

    Optional, later: machine learning foundations

    CampusX’s 100 Days of Machine Learning and 100 Days of Deep Learning are excellent, but automation work doesn’t need them. Save them for AI engineer roles that build models, not just use them.
